## 已确认构筑方向

- 以**六发编排与连锁**作为核心骨架，让前一发为后一发铺垫。
- 以**弹幕类型、弹幕 Tag 和元素反应**作为主要内容层，形成类似 Noita 的组合反馈。
- 以**抽面控制、骰面返还、复制和风险收益**作为少量高稀有度构筑，提供类似大巴扎的引擎成长感。
- 基础事件负责“发射什么”；开火时事件负责“如何发射”；命中时事件负责“命中后发生什么”；开火后事件负责“如何改变后续枪膛”。
- 单个词条保持简单，强度主要来自跨骰面、跨时刻和跨弹幕的组合；所有连锁继续受事件预算限制。

## 后续扩展参考池

- 这些候选只作为灵感池，不视为已批准实施范围。

### 弹幕类型或抽面规则

- **雷电球**：缓慢飞行、可穿透敌人的雷电元素弹幕。
- **收尾者**：绑定的骰面必定在当前弹夹最后一发才会被抽到。

### 开火时事件

- **电磁共鸣**：发射雷电球时，在一定范围内随机选择其他雷电球并产生链式反应；雷电球之间生成能伤害敌人的闪电链。
- **特斯拉**：本轮弹夹每发射一颗雷电类型弹幕，事件绑定骰面的基础弹幕伤害增加 `5%`；换弹后重置本轮成长。

### 命中时事件

- **呼应协同**：同类弹幕命中敌人时，触发一次事件绑定骰面；最多触发 `4` 次，次数耗尽后该骰面视为已消耗。

### 开火后事件

- **链式反应**：将下一发子弹使用的骰面配置覆盖为当前骰面配置，但复制后的开火后槽位为空，防止无限复制链式反应。

## 设计时必须确认

- `收尾者` 更接近抽面约束而非弹丸物理类型，设计时决定其最终资源类别和装备位置。
- 电磁共鸣的搜索半径、链接数量、每条闪电伤害、同一敌人的结算次数和雷电球销毁规则。
- 特斯拉的 `5%` 使用加法叠层还是乘法叠层，以及成长修改运行时快照还是本轮临时修正器。
- 呼应协同的“同类”按弹幕类型、弹幕 Tag 还是两者共同判定；重复触发是否允许继续触发该骰面的命中事件。
- 链式反应覆盖的是下一次抽中的骰面快照，还是直接改变枪膛内骰面配置；被覆盖骰面的原始消耗归属需要明确。
